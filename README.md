#  AI Job Finder Telegram Bot

An AI-powered job discovery and matching application built with Python.
It collects job opportunities from multiple APIs and helps users find
relevant positions based on their skills, experience, and preferences.
## 📸 Project Screenshot

![AI Job Finder Screenshot](screenshot/Screenshot%202026-10-11%20144843.png)


##  Features

-  Resume analysis using Gemini AI
-  Job matching based on skills, experience, and target roles
-  Fetches jobs from multiple sources:
  - Arbeitnow
  - Remotive
  - IndianAPI
-  Interactive Telegram bot
-  Supabase integration for storing user profiles and preferences
-  Environment variables for API credentials
-  Automated job filtering and matching pipeline

##  Tech Stack

- Python
- Gemini AI API
- Telegram Bot API
- Supabase
- REST APIs
- Git and GitHub
